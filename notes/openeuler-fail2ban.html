OpenEuler22.03安装 Fail2Ban防SSH暴力破解

安全与网络 · 约 8388 字 · 查看 Markdown 原文

背景

这边要两台服务器开放公网给总部研发访问，由于全开放，决定使用开源入侵防御工具 Fail2Ban 来防护。

Fail2Ban 可以实时监控日志文件，一旦检测到暴力破解行为（如多次登录失败），就会自动使用防火墙（如 firewalld）将攻击者 IP 临时或永久封禁。

1.项目地址

https://github.com/fail2ban/fail2ban
因为在OpenEuler2203系统上面用yum找不到fail2ban，只能使用编译的方法进行安装
参考博客文章 Linux 命令工具 fail2ban 使用指南

2.安装步骤

1. 安装依赖

dnf install python3-systemd -y
dnf install python3-devel gcc -y

2. 编译安装 Fail2Ban

也可以手动git下载源码包再编译安装

git clone https://github.com/fail2ban/fail2ban.git
cd fail2ban
python3 setup.py install

若看到类似“Installation successful”输出，说明编译安装成功。

3.配置 Fail2Ban 防护 SSH

3.1 编辑配置文件

vim /etc/fail2ban/jail.conf

3.2 推荐配置（SSH 防护）

[DEFAULT] 是全局默认值，其他 jail 继承或覆盖
找到[DEFAULT] 开头的块去编辑

[DEFAULT]
ignoreip = 127.0.0.1/8 ::1
bantime = 24h
findtime = 60m
maxretry = 5
backend = systemd
banaction = firewallcmd-ipset

[sshd]
enabled = true
mode = aggressive
port = 16822
logpath = %(sshd_log)s
filter = sshd

我这边使用配置sshd文件好区分

在 /etc/fail2ban/jail.d 新建文件sshd.local

[sshd]
enabled = true
port = ssh
filter = sshd
logpath = /var/log/secure
maxretry = 3
bantime = 300
findtime = 600
ignoreip = 127.0.0.1 10.20.3.0/24 112.51.25.139

配置说明

参数 说明
<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.03);">ignoreip</font> 白名单 IP，支持多个，空格分隔
<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.03);">bantime</font> 封禁时长，<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.03);">-1</font>
为永久封禁
<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.03);">findtime</font> 检测时间窗口
<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.03);">maxretry</font> 最大失败次数，超过即封禁
<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.03);">banaction</font> 使用 firewalld 封禁 IP
<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.03);">backend</font> 使用 systemd 读取日志，稳定性更好
<font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.03);">mode</font> <font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.03);">aggressive</font>
模式匹配更多错误类型

4. 启动Fail2Ban服务

复制 systemd 服务文件

cp build/fail2ban.service /etc/systemd/system/

修改服务文件（解决启动失败问题）

vim /etc/systemd/system/fail2ban.service

添加环境变量（根据实际 Python 路径调整）：

Environment="PYTHONPATH=/usr/local/lib/python3.9/site-packages/"

建议注释掉 <font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.03);">PartOf</font> 行，避免不必要的重启依赖。

systemctl daemon-reload
systemctl restart fail2ban.service
systemctl status fail2ban.service

启动并检查服务状态

5.常用 Fail2Ban 命令

操作 命令
查看服务状态 <font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.03);">fail2ban-client status</font>
查看 sshd 防护详情 <font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.03);">fail2ban-client status sshd</font>
手动封禁 IP <font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.03);">fail2ban-client set sshd banip 10.0.0.111</font>
手动解封 IP <font style="color:rgba(0, 0, 0, 0.9);background-color:rgba(0, 0, 0, 0.03);">fail2ban-client set sshd unbanip 10.0.0.111</font>
