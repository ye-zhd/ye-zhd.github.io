企业微信群机器人接口速查

官方文档：消息推送（群机器人）配置说明 配套代码：wecom_robot.py（零第三方依赖，仅标准库）

群机器人本质是一个带 key 的 webhook，向它发 HTTP POST 即可往群里推消息。共支持 8 种消息类型：

msgtype 说明 需要素材上传
text 文本，支持 @成员 / @所有人 否
markdown Markdown（有限语法 + 3 种字体颜色） 否
markdown_v2 Markdown V2（表格、代码块、图片，不支持颜色与 @） 否
image 图片（base64 + md5） 否
news 图文链接，1~8 条 否
file 文件 是，type=file
voice 语音（AMR） 是，type=voice
template_card 模板卡片：text_notice / news_notice 卡片内附件可选

一、安全：webhook 必须藏起来

官方原文提醒：「一定要保护好消息推送的 webhook 地址，避免泄漏！不要分享到 github、博客等可被公开查阅的地方」。key 一旦泄露，任何人都能往群里发消息。

约定：

  • 代码、文档、截图、Git 提交中一律只出现占位符 ${WECOM_WEBHOOK}、YOUR_KEY_HERE。
  • 真实地址只放在环境变量或被 .gitignore 排除的 .env 里。
  • 日志与异常输出统一打码：.../send?key=***。
  • 若曾经明文提交过，请到群机器人设置里重置 webhook（换 key），并清理历史提交。

配置方式（任选其一）：

# Git Bash / Linux
export WECOM_WEBHOOK='https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY_HERE'
export WECOM_WEBHOOK_KEY='YOUR_KEY_HERE'   # 或只填 key

# PowerShell
$env:WECOM_WEBHOOK = "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY_HERE"

# .env（复制自 .env.example，已被 .gitignore 排除）
WECOM_WEBHOOK=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY_HERE

读取优先级：显式传参 > WECOM_WEBHOOK > .env > WECOM_WEBHOOK_KEY（自动拼地址）。

二、快速开始

from wecom_robot import WeComRobot

bot = WeComRobot()                      # 从环境变量 / .env 读取
bot.send_text("福州今日天气：26℃，多云")
bot.send_markdown("**告警** <font color=\"warning\">CPU 92%</font>")
bot.send_file("./report.xlsx")         # 内部自动完成 upload_media

只看请求体、不联网（适合自测和写文档）：

python wecom_robot.py demo              # 打印 8 类消息体
python wecom_robot.py check             # 检查配置，输出脱敏地址
python wecom_robot.py text "hi" --dry-run

原生 curl 形态：

curl -X POST "$WECOM_WEBHOOK" \
  -H 'Content-Type: application/json' \
  -d '{"msgtype":"text","text":{"content":"hello world"}}'

三、各类型接口实例

3.1 text 文本

{
  "msgtype": "text",
  "text": {
    "content": "广州今日天气：29度，大部分多云",
    "mentioned_list": ["wangqing", "@all"],
    "mentioned_mobile_list": ["13800001111", "@all"]
  }
}
  • content ≤ 2048 字节，UTF-8；支持 <@userid> 扩展语法。
  • mentioned_list 放 userid，mentioned_mobile_list 放手机号，@all 提醒所有人。
bot.send_text("服务器告警，请处理", mentioned_list=["@all"])

3.2 markdown

{
  "msgtype": "markdown",
  "markdown": {
    "content": "实时新增用户反馈<font color=\"warning\">132例</font>\n>类型:<font color=\"comment\">用户反馈</font>"
  }
}
  • content ≤ 4096 字节。
  • 支持 1~6 级标题、**加粗**、链接、行内代码、> 引用、<@userid>。
  • 字体颜色只有 3 种：info（绿）、comment（灰）、warning（橙红）。
bot.send_markdown("## 日报\n**新增告警** <font color=\"warning\">3</font> 条")

3.3 markdown_v2

{
  "msgtype": "markdown_v2",
  "markdown_v2": {
    "content": "# 周报\n| 项目 | 数值 |\n| --- | --- |\n| 告警 | 3 |\n\n```\n独立代码块\n```"
  }
}
  • content ≤ 4096 字节；支持斜体、多级列表/引用、链接、图片、分割线、代码块、表格。
  • 不支持字体颜色和 @成员；客户端 4.1.36（安卓 4.1.38）以下显示为纯文本。
bot.send_markdown_v2("# 周报\n| 项目 | 数值 |\n| :--- | ---: |\n| 告警 | 3 |")

3.4 image 图片

{
  "msgtype": "image",
  "image": {
    "base64": "DATA",
    "md5": "MD5"
  }
}
  • 图片（base64 前）≤ 2M，仅 JPG / PNG；md5 是原始文件内容的 MD5。
bot.send_image("./chart.png")   # 自动读取文件、算 md5、转 base64

3.5 news 图文

{
  "msgtype": "news",
  "news": {
    "articles": [
      {
        "title": "中秋节礼品领取",
        "description": "今年中秋节公司有豪礼相送",
        "url": "https://www.qq.com",
        "picurl": "https://example.com/pic.png"
      }
    ]
  }
}
  • articles 1~8 条；title ≤128 字节、description ≤512 字节，超出自动截断。
  • 图片建议大图 1068×455、小图 150×150。
bot.send_news([{"title": "运维知识库", "url": "https://example.com/kb",
                "description": "常用命令速查"}])

3.6 file 文件

{
  "msgtype": "file",
  "file": { "media_id": "3a8asd892asd8asd" }
}

media_id 必须先通过 upload_media 获取（见第四节）。

from wecom_robot import file_payload

bot.send_file("./拨测结果.xlsx")                 # 上传 + 发送一步完成
media_id = bot.upload_media("./拨测结果.xlsx", "file")
bot.send_raw(file_payload(media_id))            # 或复用 media_id 手动发送

3.7 voice 语音

{
  "msgtype": "voice",
  "voice": { "media_id": "MEDIA_ID" }
}
  • 仅 AMR 格式，≤ 2M，播放时长 ≤ 60s。
bot.send_voice("./notice.amr")

3.8 template_card 模板卡片

两种 card_type，字段很多，日常用构造函数生成最省事。

文本通知 text_notice（适合告警 / 数据播报）：

{
  "msgtype": "template_card",
  "template_card": {
    "card_type": "text_notice",
    "source": { "desc": "运维告警", "desc_color": 0 },
    "main_title": { "title": "磁盘使用率告警", "desc": "生产环境 /data 分区" },
    "emphasis_content": { "title": "92%", "desc": "当前使用率" },
    "sub_title_text": "请及时清理日志或扩容",
    "horizontal_content_list": [
      { "keyname": "主机", "value": "node-01" },
      { "keyname": "详情", "value": "点击查看", "type": 1, "url": "https://example.com/dashboard" }
    ],
    "jump_list": [
      { "type": 1, "url": "https://example.com/dashboard", "title": "监控面板" }
    ],
    "card_action": { "type": 1, "url": "https://example.com/dashboard" }
  }
}

图文展示 news_notice（适合周报 / 公告）：

{
  "msgtype": "template_card",
  "template_card": {
    "card_type": "news_notice",
    "source": { "desc": "运维周报", "desc_color": 0 },
    "main_title": { "title": "本周运维周报" },
    "card_image": { "url": "https://example.com/banner.png", "aspect_ratio": 1.3 },
    "vertical_content_list": [
      { "title": "告警数", "desc": "较上周下降 12%" }
    ],
    "card_action": { "type": 1, "url": "https://example.com/weekly" }
  }
}

关键约束：

字段 约束
card_action 必填，type=1 跳 url、type=2 跳小程序
main_title.title news_notice 必填；text_notice 中与 sub_title_text 二选一
card_image news_notice 必填，aspect_ratio 建议 1.3~2.25
horizontal_content_list ≤6 条，type 为 1=url / 2=附件 / 3=成员详情
vertical_content_list ≤4 条，仅 news_notice
jump_list ≤3 条
quote_area 引用文献样式，建议不与 emphasis_content 共用 
from wecom_robot import text_notice_card, news_notice_card

card = text_notice_card(
    title="磁盘使用率告警",
    url="https://example.com/dashboard",
    desc="生产环境 /data 分区",
    emphasis_title="92%",
    emphasis_desc="当前使用率",
)
bot.send_template_card(card)

四、素材上传 upload_media

file、voice 都要先上传：

POST https://qyapi.weixin.qq.com/cgi-bin/webhook/upload_media?key=YOUR_KEY_HERE&type=file
Content-Type: multipart/form-data
  • 表单文件字段名为 media，需带 filename、filelength、Content-Type。
  • key 取自 webhook 地址的查询参数；type 为 file 或 voice。
  • 返回：{"errcode":0,"errmsg":"ok","type":"file","media_id":"...","created_at":"..."}。
  • media_id 仅 3 天内有效，且只能被上传它的那个机器人使用。
curl -F "media=@report.xlsx;type=application/octet-stream" \
  "$WECOM_WEBHOOK_UPLOAD_URL&type=file"

media_id = bot.upload_media("./report.xlsx", "file")
bot.send_raw({"msgtype": "file", "file": {"media_id": media_id}})

五、限制与排错

项目 限制
发送频率 每个机器人 ≤20 条/分钟
text.content ≤2048 字节
markdown / markdown_v2 ≤4096 字节
image ≤2M，JPG / PNG
news.articles 1~8 条
上传素材 必须 >5 字节
file ≤20M
voice ≤2M、≤60s、仅 AMR
media_id 3 天有效

常见返回码：

errcode 含义 处理
0 成功 —
93000 无效 webhook / key 检查地址，必要时在群设置里重置机器人
45009 接口调用超过限制 降频，控制在 20 条/分钟内
40058 / 40001 参数不合法 / 校验失败 对照上表检查字段与字节数

返回的 errcode 非 0 时，封装会抛 WeComError（带 errcode、errmsg），异常信息中的 URL 已打码。

六、命令行速查

python wecom_robot.py check                 # 配置检查（脱敏输出）
python wecom_robot.py demo                 # 打印 8 类消息体，不发送
python wecom_robot.py text "告警"           # 发送文本
python wecom_robot.py markdown "**加粗**"   # 发送 Markdown
python wecom_robot.py markdown-v2 "# 周报"  # 发送 Markdown V2
python wecom_robot.py image ./chart.png    # 发送图片
python wecom_robot.py file ./report.xlsx   # 上传并发送文件
python wecom_robot.py voice ./notice.amr   # 发送语音
python wecom_robot.py card                 # 发送模板卡片示例
# 任意命令加 --dry-run 只打印请求体、不联网

所有示例地址均为占位符，运行前请先设置 WECOM_WEBHOOK。
