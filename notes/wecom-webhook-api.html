企业微信群机器人接口速查

官方文档：消息推送（群机器人）配置说明 配套代码：wecom_robot.py（零第三方依赖，仅标准库）

群机器人本质是一个带 key 的 webhook，向它发 HTTP POST 即可往群里推消息。共支持 8 种消息类型：

msgtype 说明 需要素材上传
text 文本，支持 @成员 / @所有人 否
markdown Markdown（有限语法 + 3 种字体颜色） 否
markdown_v2 Markdown V2（表格、代码块、图片，不支持颜色与 @） 否
image 图片（base64 + md5） 否
news 图文链接，1~8 条 否
file 文件 是，type=file
voice 语音（AMR） 是，type=voice
template_card 模板卡片：text_notice / news_notice 卡片内附件可选

一、安全：webhook 必须藏起来

官方原文提醒：「一定要保护好消息推送的 webhook 地址，避免泄漏！不要分享到 github、博客等可被公开查阅的地方」。key 一旦泄露，任何人都能往群里发消息。

约定：

  • 代码、文档、截图、Git 提交中一律只出现占位符 ${WECOM_WEBHOOK}、YOUR_KEY_HERE。
  • 真实地址只放在环境变量或被 .gitignore 排除的 .env 里。
  • 日志与异常输出统一打码：.../send?key=***。
  • 若曾经明文提交过，请到群机器人设置里重置 webhook（换 key），并清理历史提交。

配置方式（任选其一）：

# Git Bash / Linux
export WECOM_WEBHOOK='https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY_HERE'
export WECOM_WEBHOOK_KEY='YOUR_KEY_HERE'   # 或只填 key

# PowerShell
$env:WECOM_WEBHOOK = "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY_HERE"

# .env（复制自 .env.example，已被 .gitignore 排除）
WECOM_WEBHOOK=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=YOUR_KEY_HERE

读取优先级：显式传参 > WECOM_WEBHOOK > .env > WECOM_WEBHOOK_KEY（自动拼地址）。

二、快速开始

from wecom_robot import WeComRobot

bot = WeComRobot()                      # 从环境变量 / .env 读取
bot.send_text("福州今日天气：26℃，多云")
bot.send_markdown("**告警** <font color=\"warning\">CPU 92%</font>")
bot.send_file("./report.xlsx")         # 内部自动完成 upload_media

只看请求体、不联网（适合自测和写文档）：

python wecom_robot.py demo              # 打印 8 类消息体
python wecom_robot.py check             # 检查配置，输出脱敏地址
python wecom_robot.py text "hi" --dry-run

原生 curl 形态：

curl -X POST "$WECOM_WEBHOOK" \
  -H 'Content-Type: application/json' \
  -d '{"msgtype":"text","text":{"content":"hello world"}}'

三、各类型接口实例

3.1 text 文本

{
  "msgtype": "text",
  "text": {
    "content": "广州今日天气：29度，大部分多云",
    "mentioned_list": ["wangqing", "@all"],
    "mentioned_mobile_list": ["13800001111", "@all"]
  }
}
  • content ≤ 2048 字节，UTF-8；支持 <@userid> 扩展语法。
  • mentioned_list 放 userid，mentioned_mobile_list 放手机号，@all 提醒所有人。
bot.send_text("服务器告警，请处理", mentioned_list=["@all"])

3.2 markdown

{
  "msgtype": "markdown",
  "markdown": {
    "content": "实时新增用户反馈<font color=\"warning\">132例</font>\n>类型:<font color=\"comment\">用户反馈</font>"
  }
}
  • content ≤ 4096 字节。
  • 支持 1~6 级标题、**加粗**、链接、行内代码、> 引用、<@userid>。
  • 字体颜色只有 3 种：info（绿）、comment（灰）、warning（橙红）。
bot.send_markdown("## 日报\n**新增告警** <font color=\"warning\">3</font> 条")

3.3 markdown_v2

{
  "msgtype": "markdown_v2",
  "markdown_v2": {
    "content": "# 周报\n| 项目 | 数值 |\n| --- | --- |\n| 告警 | 3 |\n\n```\n独立代码块\n```"
  }
}
  • content ≤ 4096 字节；支持斜体、多级列表/引用、链接、图片、分割线、代码块、表格。
  • 不支持字体颜色和 @成员；客户端 4.1.36（安卓 4.1.38）以下显示为纯文本。
bot.send_markdown_v2("# 周报\n| 项目 | 数值 |\n| :--- | ---: |\n| 告警 | 3 |")

3.4 image 图片

{
  "msgtype": "image",
  "image": {
    "base64": "DATA",
    "md5": "MD5"
  }
}
  • 图片（base64 前）≤ 2M，仅 JPG / PNG；md5 是原始文件内容的 MD5。
bot.send_image("./chart.png")   # 自动读取文件、算 md5、转 base64

3.5 news 图文

{
  "msgtype": "news",
  "news": {
    "articles": [
      {
        "title": "中秋节礼品领取",
        "description": "今年中秋节公司有豪礼相送",
        "url": "https://www.qq.com",
        "picurl": "https://example.com/pic.png"
      }
    ]
  }
}
  • articles 1~8 条；title ≤128 字节、description ≤512 字节，超出自动截断。
  • 图片建议大图 1068×455、小图 150×150。
bot.send_news([{"title": "运维知识库", "url": "https://example.com/kb",
                "description": "常用命令速查"}])

3.6 file 文件

{
  "msgtype": "file",
  "file": { "media_id": "3a8asd892asd8asd" }
}

media_id 必须先通过 upload_media 获取（见第四节）。

from wecom_robot import file_payload

bot.send_file("./拨测结果.xlsx")                 # 上传 + 发送一步完成
media_id = bot.upload_media("./拨测结果.xlsx", "file")
bot.send_raw(file_payload(media_id))            # 或复用 media_id 手动发送

3.7 voice 语音

{
  "msgtype": "voice",
  "voice": { "media_id": "MEDIA_ID" }
}
  • 仅 AMR 格式，≤ 2M，播放时长 ≤ 60s。
bot.send_voice("./notice.amr")

3.8 template_card 模板卡片

两种 card_type，字段很多，日常用构造函数生成最省事。

文本通知 text_notice（适合告警 / 数据播报）：

{
  "msgtype": "template_card",
  "template_card": {
    "card_type": "text_notice",
    "source": { "desc": "运维告警", "desc_color": 0 },
    "main_title": { "title": "磁盘使用率告警", "desc": "生产环境 /data 分区" },
    "emphasis_content": { "title": "92%", "desc": "当前使用率" },
    "sub_title_text": "请及时清理日志或扩容",
    "horizontal_content_list": [
      { "keyname": "主机", "value": "node-01" },
      { "keyname": "详情", "value": "点击查看", "type": 1, "url": "https://example.com/dashboard" }
    ],
    "jump_list": [
      { "type": 1, "url": "https://example.com/dashboard", "title": "监控面板" }
    ],
    "card_action": { "type": 1, "url": "https://example.com/dashboard" }
  }
}

图文展示 news_notice（适合周报 / 公告）：

{
  "msgtype": "template_card",
  "template_card": {
    "card_type": "news_notice",
    "source": { "desc": "运维周报", "desc_color": 0 },
    "main_title": { "title": "本周运维周报" },
    "card_image": { "url": "https://example.com/banner.png", "aspect_ratio": 1.3 },
    "vertical_content_list": [
      { "title": "告警数", "desc": "较上周下降 12%" }
    ],
    "card_action": { "type": 1, "url": "https://example.com/weekly" }
  }
}

关键约束：

字段 约束
card_action 必填，type=1 跳 url、type=2 跳小程序
main_title.title news_notice 必填；text_notice 中与 sub_title_text 二选一
card_image news_notice 必填，aspect_ratio 建议 1.3~2.25
horizontal_content_list ≤6 条，type 为 1=url / 2=附件 / 3=成员详情
vertical_content_list ≤4 条，仅 news_notice
jump_list ≤3 条
quote_area 引用文献样式，建议不与 emphasis_content 共用 
from wecom_robot import text_notice_card, news_notice_card

card = text_notice_card(
    title="磁盘使用率告警",
    url="https://example.com/dashboard",
    desc="生产环境 /data 分区",
    emphasis_title="92%",
    emphasis_desc="当前使用率",
)
bot.send_template_card(card)

四、素材上传 upload_media

file、voice 都要先上传：

POST https://qyapi.weixin.qq.com/cgi-bin/webhook/upload_media?key=YOUR_KEY_HERE&type=file
Content-Type: multipart/form-data
  • 表单文件字段名为 media，需带 filename、filelength、Content-Type。
  • key 取自 webhook 地址的查询参数；type 为 file 或 voice。
  • 返回：{"errcode":0,"errmsg":"ok","type":"file","media_id":"...","created_at":"..."}。
  • media_id 仅 3 天内有效，且只能被上传它的那个机器人使用。
curl -F "media=@report.xlsx;type=application/octet-stream" \
  "$WECOM_WEBHOOK_UPLOAD_URL&type=file"

media_id = bot.upload_media("./report.xlsx", "file")
bot.send_raw({"msgtype": "file", "file": {"media_id": media_id}})

五、限制与排错

项目 限制
发送频率 每个机器人 ≤20 条/分钟
text.content ≤2048 字节
markdown / markdown_v2 ≤4096 字节
image ≤2M，JPG / PNG
news.articles 1~8 条
上传素材 必须 >5 字节
file ≤20M
voice ≤2M、≤60s、仅 AMR
media_id 3 天有效

常见返回码：

errcode 含义 处理
0 成功 —
93000 无效 webhook / key 检查地址，必要时在群设置里重置机器人
45009 接口调用超过限制 降频，控制在 20 条/分钟内
40058 / 40001 参数不合法 / 校验失败 对照上表检查字段与字节数

返回的 errcode 非 0 时，封装会抛 WeComError（带 errcode、errmsg），异常信息中的 URL 已打码。

python wecom_robot.py check                 # 配置检查（脱敏输出）

七、附：wecom_robot.py 完整源码

上面各节的请求体例子都出自这份脚本，零第三方依赖，只用标准库。真实 webhook 只从环境变量 / .env 读，代码里不含任何 key；日志和异常里的地址也会打码。

保存成 wecom_robot.py，配好 WECOM_WEBHOOK 就能直接跑。python wecom_robot.py demo 只打印请求体、不联网，改代码前可以先用它对照。

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
企业微信群机器人（消息推送）接口封装 —— 零第三方依赖，仅用 Python 标准库。

官方文档: https://developer.work.weixin.qq.com/document/path/91770

支持的消息类型（8 种）:
    text / markdown / markdown_v2 / image / news / file / voice / template_card
辅助接口:
    upload_media —— file、voice 需先上传获取 media_id

安全约定（重要）:
    * 真实 webhook 地址绝不写进本文件、文档或任何会提交到 Git 的文件。
    * 优先读取环境变量 WECOM_WEBHOOK；也可放在被 .gitignore 的 .env 里。
    * 只配置了 key 时可用 WECOM_WEBHOOK_KEY，由程序拼接地址。
    * 所有日志/异常输出都会对 key 做脱敏。

命令行示例:
    python wecom_robot.py check                     # 检查配置（脱敏输出）
    python wecom_robot.py demo                     # 打印 8 类消息体，不发送
    python wecom_robot.py text "服务器告警"          # 发送文本
    python wecom_robot.py markdown "**加粗**"       # 发送 Markdown
    python wecom_robot.py image ./chart.png        # 发送图片
    python wecom_robot.py file ./report.xlsx       # 上传并发送文件
    python wecom_robot.py card                     # 发送模板卡片示例
    python wecom_robot.py text "hi" --dry-run      # 只打印请求体，不联网
"""
from __future__ import annotations

import base64
import hashlib
import json
import mimetypes
import os
import re
import sys
import urllib.error
import urllib.parse
import urllib.request
import uuid
from pathlib import Path
from typing import Any

SEND_URL = "https://qyapi.weixin.qq.com/cgi-bin/webhook/send"
UPLOAD_URL = "https://qyapi.weixin.qq.com/cgi-bin/webhook/upload_media"

ENV_WEBHOOK = "WECOM_WEBHOOK"
ENV_KEY = "WECOM_WEBHOOK_KEY"

# 官方限制
MAX_TEXT_BYTES = 2048
MAX_MARKDOWN_BYTES = 4096
MAX_IMAGE_BYTES = 2 * 1024 * 1024
MAX_FILE_BYTES = 20 * 1024 * 1024
MAX_VOICE_BYTES = 2 * 1024 * 1024
MIN_UPLOAD_BYTES = 5
MAX_NEWS_ARTICLES = 8
RATE_LIMIT_PER_MINUTE = 20


class WeComError(Exception):
    """企业微信接口返回错误或网络异常。"""

    def __init__(self, message: str, errcode: int | None = None, errmsg: str | None = None):
        super().__init__(message)
        self.errcode = errcode
        self.errmsg = errmsg


def mask_webhook(url: str) -> str:
    """把 webhook 中的 key 打码，用于日志与异常信息。"""
    return re.sub(r"(key=)[^&\s'\"]+", r"\1***", url or "")


def load_dotenv(path: str | Path = ".env") -> None:
    """读取简易 .env（KEY=VALUE），不覆盖已有环境变量。"""
    p = Path(path)
    if not p.exists():
        return
    for line in p.read_text(encoding="utf-8").splitlines():
        line = line.strip()
        if not line or line.startswith("#") or "=" not in line:
            continue
        k, v = line.split("=", 1)
        os.environ.setdefault(k.strip(), v.strip().strip("\"'"))


def resolve_webhook(explicit: str | None = None) -> str:
    """按 显式参数 > 环境变量 > .env > KEY 环境变量 的顺序取得 webhook。"""
    load_dotenv()
    url = explicit or os.environ.get(ENV_WEBHOOK, "").strip()
    if url:
        return url
    key = os.environ.get(ENV_KEY, "").strip()
    if key:
        return "%s?key=%s" % (SEND_URL, key)
    raise WeComError(
        "未配置 webhook。请设置环境变量 %s（完整地址）或 %s（仅 key），"
        "或把 %s=... 写入被 .gitignore 的 .env 文件。" % (ENV_WEBHOOK, ENV_KEY, ENV_WEBHOOK)
    )


def _check_bytes(text: str, limit: int, field: str) -> None:
    size = len(text.encode("utf-8"))
    if size > limit:
        raise ValueError("%s 超出限制：%d 字节 > %d 字节" % (field, size, limit))


def _url_key(webhook: str) -> str:
    q = urllib.parse.parse_qs(urllib.parse.urlparse(webhook).query)
    key = q.get("key", [""])[0]
    if not key:
        raise WeComError("webhook 地址中缺少 key 参数，无法调用 upload_media")
    return key


# ---------------------------------------------------------------------------
# 消息体构造器：便于单独打印/自测，不依赖网络
# ---------------------------------------------------------------------------

def text_payload(
    content: str,
    mentioned_list: list[str] | None = None,
    mentioned_mobile_list: list[str] | None = None,
) -> dict:
    """文本消息，支持 @成员 / @所有人。"""
    _check_bytes(content, MAX_TEXT_BYTES, "text.content")
    body: dict[str, Any] = {"content": content}
    if mentioned_list:
        body["mentioned_list"] = mentioned_list
    if mentioned_mobile_list:
        body["mentioned_mobile_list"] = mentioned_mobile_list
    return {"msgtype": "text", "text": body}


def markdown_payload(content: str) -> dict:
    """Markdown（支持有限语法与 3 种字体颜色，支持 <@userid>）。"""
    _check_bytes(content, MAX_MARKDOWN_BYTES, "markdown.content")
    return {"msgtype": "markdown", "markdown": {"content": content}}


def markdown_v2_payload(content: str) -> dict:
    """Markdown V2（支持表格/代码块/图片，不支持字体颜色与 @）。"""
    _check_bytes(content, MAX_MARKDOWN_BYTES, "markdown_v2.content")
    return {"msgtype": "markdown_v2", "markdown_v2": {"content": content}}


def image_payload(image_path: str | Path) -> dict:
    """图片消息：本地图片转 base64 + md5（≤2M，JPG/PNG）。"""
    p = Path(image_path)
    data = p.read_bytes()
    if len(data) > MAX_IMAGE_BYTES:
        raise ValueError("图片超过 2M：%d 字节" % len(data))
    if p.suffix.lower() not in (".jpg", ".jpeg", ".png"):
        raise ValueError("图片仅支持 JPG / PNG：%s" % p.suffix)
    return {
        "msgtype": "image",
        "image": {
            "base64": base64.b64encode(data).decode("ascii"),
            "md5": hashlib.md5(data).hexdigest(),
        },
    }


def news_payload(articles: list[dict]) -> dict:
    """图文消息，1~8 条；每条需 title、url，可选 description、picurl。"""
    if not 1 <= len(articles) <= MAX_NEWS_ARTICLES:
        raise ValueError("图文条数必须在 1~%d 之间" % MAX_NEWS_ARTICLES)
    for a in articles:
        if not a.get("title") or not a.get("url"):
            raise ValueError("每条图文必须包含 title 和 url")
    return {"msgtype": "news", "news": {"articles": articles}}


def file_payload(media_id: str) -> dict:
    """文件消息，media_id 来自 upload_media。"""
    return {"msgtype": "file", "file": {"media_id": media_id}}


def voice_payload(media_id: str) -> dict:
    """语音消息，media_id 来自 upload_media（仅 AMR）。"""
    return {"msgtype": "voice", "voice": {"media_id": media_id}}


def template_card_payload(card: dict) -> dict:
    """模板卡片：card_type 为 text_notice 或 news_notice。"""
    if card.get("card_type") not in ("text_notice", "news_notice"):
        raise ValueError("card_type 必须是 text_notice 或 news_notice")
    return {"msgtype": "template_card", "template_card": card}


def text_notice_card(
    title: str,
    url: str,
    desc: str = "",
    emphasis_title: str = "",
    emphasis_desc: str = "",
    sub_title: str = "",
    horizontal: list[dict] | None = None,
    jumps: list[dict] | None = None,
    source_desc: str = "运维告警",
) -> dict:
    """构造常用的「文本通知模版卡片」。"""
    card: dict[str, Any] = {
        "card_type": "text_notice",
        "source": {"desc": source_desc, "desc_color": 0},
        "main_title": {"title": title, "desc": desc},
        "card_action": {"type": 1, "url": url},
    }
    if emphasis_title:
        card["emphasis_content"] = {"title": emphasis_title, "desc": emphasis_desc}
    if sub_title:
        card["sub_title_text"] = sub_title
    if horizontal:
        card["horizontal_content_list"] = horizontal
    if jumps:
        card["jump_list"] = jumps
    return card


def news_notice_card(
    title: str,
    image_url: str,
    url: str,
    desc: str = "",
    vertical: list[dict] | None = None,
    horizontal: list[dict] | None = None,
    source_desc: str = "运维告警",
) -> dict:
    """构造常用的「图文展示模版卡片」。"""
    card: dict[str, Any] = {
        "card_type": "news_notice",
        "source": {"desc": source_desc, "desc_color": 0},
        "main_title": {"title": title, "desc": desc},
        "card_image": {"url": image_url, "aspect_ratio": 1.3},
        "card_action": {"type": 1, "url": url},
    }
    if vertical:
        card["vertical_content_list"] = vertical
    if horizontal:
        card["horizontal_content_list"] = horizontal
    return card


# ---------------------------------------------------------------------------
# 客户端
# ---------------------------------------------------------------------------

class WeComRobot:
    """企业微信群机器人客户端。

    Args:
        webhook: 完整 webhook 地址；不传则从环境变量 / .env 读取。
        timeout: HTTP 超时秒数。
        dry_run: 为 True 时只返回请求体、不发起网络请求。
    """

    def __init__(self, webhook: str | None = None, timeout: int = 10, dry_run: bool = False):
        self.webhook = resolve_webhook(webhook)
        self.timeout = timeout
        self.dry_run = dry_run

    def __repr__(self) -> str:
        return "<WeComRobot %s>" % mask_webhook(self.webhook)

    def _post_json(self, payload: dict) -> dict:
        if self.dry_run:
            return {"errcode": 0, "errmsg": "dry-run", "payload": payload}
        data = json.dumps(payload, ensure_ascii=False).encode("utf-8")
        req = urllib.request.Request(
            self.webhook,
            data=data,
            headers={"Content-Type": "application/json; charset=utf-8"},
            method="POST",
        )
        return self._request(req)

    def _post_multipart(self, url: str, file_path: Path, media_type: str) -> dict:
        data = file_path.read_bytes()
        boundary = "----WeComBoundary" + uuid.uuid4().hex
        head = (
            "--%s\r\n"
            'Content-Disposition: form-data; name="media"; filename="%s"; filelength=%d\r\n'
            "Content-Type: %s\r\n\r\n"
            % (
                boundary,
                file_path.name,
                len(data),
                mimetypes.guess_type(file_path.name)[0] or "application/octet-stream",
            )
        ).encode("utf-8")
        body = head + data + ("\r\n--%s--\r\n" % boundary).encode("utf-8")
        req = urllib.request.Request(
            url,
            data=body,
            headers={"Content-Type": "multipart/form-data; boundary=%s" % boundary},
            method="POST",
        )
        return self._request(req)

    def _request(self, req: urllib.request.Request) -> dict:
        try:
            with urllib.request.urlopen(req, timeout=self.timeout) as resp:
                result = json.loads(resp.read().decode("utf-8"))
        except urllib.error.HTTPError as e:
            raise WeComError("HTTP %s：%s" % (e.code, mask_webhook(getattr(req, "full_url", "")))) from e
        except urllib.error.URLError as e:
            raise WeComError("网络异常：%s（%s）" % (e.reason, mask_webhook(getattr(req, "full_url", "")))) from e
        except json.JSONDecodeError as e:
            raise WeComError("响应不是合法 JSON：%s" % e) from e
        if result.get("errcode") != 0:
            raise WeComError(
                "接口返回错误：errcode=%s errmsg=%s" % (result.get("errcode"), result.get("errmsg")),
                errcode=result.get("errcode"),
                errmsg=result.get("errmsg"),
            )
        return result

    # -- 8 种消息类型 -------------------------------------------------------

    def send_text(self, content: str, mentioned_list=None, mentioned_mobile_list=None) -> dict:
        return self._post_json(text_payload(content, mentioned_list, mentioned_mobile_list))

    def send_markdown(self, content: str) -> dict:
        return self._post_json(markdown_payload(content))

    def send_markdown_v2(self, content: str) -> dict:
        return self._post_json(markdown_v2_payload(content))

    def send_image(self, image_path: str | Path) -> dict:
        return self._post_json(image_payload(image_path))

    def send_news(self, articles: list[dict]) -> dict:
        return self._post_json(news_payload(articles))

    def send_file(self, file_path: str | Path) -> dict:
        media_id = self.upload_media(file_path, "file")
        return self._post_json(file_payload(media_id))

    def send_voice(self, voice_path: str | Path) -> dict:
        media_id = self.upload_media(voice_path, "voice")
        return self._post_json(voice_payload(media_id))

    def send_template_card(self, card: dict) -> dict:
        return self._post_json(template_card_payload(card))

    def send_raw(self, payload: dict) -> dict:
        """发送自定义/未来新增的消息类型。"""
        return self._post_json(payload)

    # -- 素材上传 -----------------------------------------------------------

    def upload_media(self, file_path: str | Path, media_type: str = "file") -> str:
        """上传素材并返回 media_id（仅 3 天内有效，且只能被该机器人使用）。"""
        if media_type not in ("file", "voice"):
            raise ValueError("media_type 只能是 file 或 voice")
        p = Path(file_path)
        if not p.is_file():
            raise FileNotFoundError("文件不存在：%s" % p)
        size = p.stat().st_size
        if size <= MIN_UPLOAD_BYTES:
            raise ValueError("文件必须大于 5 字节")
        limit = MAX_VOICE_BYTES if media_type == "voice" else MAX_FILE_BYTES
        if size > limit:
            raise ValueError("文件超过 %d 字节限制：%d" % (limit, size))
        if media_type == "voice" and p.suffix.lower() != ".amr":
            raise ValueError("语音仅支持 AMR 格式，且时长不超过 60s")
        if self.dry_run:
            return "DRY_RUN_MEDIA_ID"
        url = "%s?key=%s&type=%s" % (UPLOAD_URL, _url_key(self.webhook), media_type)
        result = self._post_multipart(url, p, media_type)
        media_id = result.get("media_id")
        if not media_id:
            raise WeComError("上传成功但未返回 media_id：%s" % result)
        return media_id

def main(argv: list[str]) -> int:
    args = [a for a in argv if a != "--dry-run"]
    dry_run = "--dry-run" in argv
    cmd = args[0] if args else "demo"

    if cmd == "demo":
        for name, payload in demo_payloads():
            print("\n### %s" % name)
            print(json.dumps(payload, ensure_ascii=False, indent=2))
        print("\n（demo 仅打印请求体，未发送任何消息）")
        return 0

    if cmd == "check":
        try:
            bot = WeComRobot(dry_run=dry_run)
            print("webhook 已配置：%s" % mask_webhook(bot.webhook))
            return 0
        except WeComError as e:
            print("配置检查失败：%s" % e)
            return 1

    try:
        bot = WeComRobot(dry_run=dry_run)
    except WeComError as e:
        print("初始化失败：%s" % e)
        return 1

    try:
        if cmd == "text":
            result = bot.send_text(args[1], ["@all"] if "--all" in args else None)
        elif cmd == "markdown":
            result = bot.send_markdown(args[1])
        elif cmd == "markdown-v2":
            result = bot.send_markdown_v2(args[1])
        elif cmd == "image":
            result = bot.send_image(args[1])
        elif cmd == "file":
            result = bot.send_file(args[1])
        elif cmd == "voice":
            result = bot.send_voice(args[1])
        elif cmd == "card":
            result = bot.send_template_card(demo_payloads()[7][1]["template_card"])
        else:
            print("未知命令：%s" % cmd)
            print("可用：demo / check / text / markdown / markdown-v2 / image / file / voice / card")
            return 2
        print(json.dumps(result, ensure_ascii=False, indent=2))
        return 0
    except (IndexError, ValueError, FileNotFoundError, WeComError) as e:
        print("发送失败：%s" % e)
        return 1


if __name__ == "__main__":
    sys.exit(main(sys.argv[1:]))
